# 🛥️ AquaLuxe — Premium Yacht Rental Website

A modern, fully responsive luxury yacht rental platform built with **React + Vite + Tailwind CSS**.

![AquaLuxe Banner](https://images.unsplash.com/photo-1567899378494-47b22a2ae96a?q=80&w=1200&auto=format&fit=crop)

## ✨ Features

- 🎬 **Video Hero Section** with Parallax effect
- 🌙 **Dark/Light Mode** with localStorage persistence
- 💰 **Multi-Currency Support** (USD, EUR, GBP, BDT)
- 🔍 **Advanced Filtering** (Category, Price Range, Search)
- ❤️ **Wishlist System** (persistent across sessions)
- 📋 **Yacht Details Modal** with features list
- 📅 **Custom Date Picker** (theme-matched)
- 🎫 **Multi-Step Booking Wizard** (3 steps)
- ✨ **Extra Services** (Chef, Photographer, Spa, etc.)
- 🗺️ **Interactive Map** with 6 global destinations
- 📊 **Animated Counters**
- 🃏 **3D Tilt Cards** on hover
- 💬 **Live Chat Widget**
- ❓ **FAQ Accordion**
- 👤 **User Dashboard** (bookings, wishlist, settings)
- 📝 **Blog Section** with featured posts
- 🎬 **Smooth Page Transitions** (Framer Motion)
- ⬆️ **Scroll to Top** button
- 📱 **Fully Responsive** (mobile, tablet, desktop)

## 🛠️ Tech Stack

| Tech | Purpose |
|------|---------|
| ⚛️ React 19 | UI Framework |
| ⚡ Vite | Build Tool |
| 🎨 Tailwind CSS | Styling |
| 🧭 React Router | Multi-page navigation |
| 🎬 Framer Motion | Advanced animations |
| 🗺️ Leaflet | Interactive map |
| 📦 Lucide React | Icons |
| 🎯 Context API | Global state management |
